Brauzerda ko'rish: `video-candidates/preview.html` ni oching.

## Papkalar

- `hero/`, `products/` — tayyor 3–4 soniyalik kesilgan variantlar
  (mp4 + webm + poster .jpg, ovozsiz, loop uchun).
  Hero = 1920x1080, mahsulotlar = 1280x720, 25fps —
  saytdagi mavjud fayllar bilan bir xil format.
- `_originals/` — Pexels'dan yuklangan to'liq original fayllar (377 MB),
  agar boshqa joyidan kesish kerak bo'lsa.
